Україна — Стаціонар

Епізод стаціонарного лікування (пролікований випадок)

Госпіталізація, виписка, результат лікування і ліжко-дні — основа для форми 066/о, руху хворих (007/о), групування за ДСГ і собівартості пролікованого випадку.

Що включено

Епізод стаціонарного лікування

  • Номер медичної карти стаціонарного хворого (ф. 003/о) — автонумерація
  • Пацієнт, відділення, лікуючий лікар, заклад
  • Вид госпіталізації: планова / екстрена / переведення / самозвернення
  • Ким направлений: ПМД / ЕМД / самозвернення / інший заклад
  • Стани: чернетка → госпіталізовано → виписано (або скасовано)
  • Результат лікування і наслідок (виписаний, переведений, самовільно залишив, помер) з перевіркою узгодженості
  • Журнал змін і активності (chatter)

Ліжко-дні та облік

  • Ліжко-дні за календарними датами в часовому поясі закладу: день поступлення і день виписки — один ліжко-день; поступив і вибув того ж дня — 1 ліжко-день
  • Довідник відділень стаціонару (профіль, завідувач)
  • Звіт «Стаціонар»: pivot / graph за відділеннями і місяцями
  • Доступ лише для груп UA Medecin User / Manager, правила за компаніями (мультикомпанійність)

Ліжковий фонд і рух хворих (ф. 007/о)

Ліжка і переведення

  • Ліжка відділень: палата, номер, профіль ліжка, дати розгортання/згортання
  • Ліжковий фонд, кількість пацієнтів і вільних ліжок у відділенні
  • Ліжко в епізоді з перевіркою зайнятості
  • Переведення між відділеннями з історією

Звіти

  • Листок обліку руху хворих і ліжкового фонду (ф. 007/о) за добу, PDF: на початок доби, поступило, переведено, виписано, померло, на кінець доби, вільні ліжка, ліжко-дні — баланс сходиться
  • Показники за довільний період у розрізі відділень: днів зайнятості ліжка на рік, обіг ліжка, середня тривалість перебування, летальність

Діагнози та втручання

Типізовані діагнози за МКХ-10

  • Діагноз закладу, що направив; при госпіталізації; клінічний; заключний; патолого-анатомічний; супутній; ускладнення
  • Ознака «виявлено вперше в житті» і дата встановлення
  • Рівно один заключний діагноз у виписаного епізоду — перевірка при виписці

Хірургічні втручання

  • Код втручання з довідника (під НК 026:2021 / АКМВ), назва, дата
  • Хірург, анестезіолог, вид знеболення
  • Екстреність, ускладнення після втручання
  • Заключний діагноз + втручання — вхідні дані для ДСГ

Нормативна база

Наказ МОЗ України від 14.02.2012 № 110 — форми первинної облікової документації (003/о, 066/о, 007/о) та інструкції щодо їх заповнення.
