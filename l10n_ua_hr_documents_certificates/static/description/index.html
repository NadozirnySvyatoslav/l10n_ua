Налаштування типів довідок

Загальні налаштування

  • Код та назва типу
  • Опис призначення
  • Термін дії (днів)
  • Послідовність нумерації

Вимоги до даних

  • Потребує інформацію про зарплату
  • Потребує вказання періоду
  • Потребує вказання призначення

Довідка

Основні дані

  • Номер довідки (автоматичний)
  • Тип довідки
  • Працівник
  • Дата заявки
  • Дата видачі
  • Дійсна до

Додаткові дані

  • Куди подається (призначення)
  • Період (для довідок про доходи)
  • Поточна зарплата (автоматично)
  • Сума доходів за період
  • Кількість копій
  • Ким видано

Автоматичне заповнення

  • Зарплата — автоматично з трудового договору або hr.version
  • Стаж — автоматичний розрахунок на основі дати прийняття
  • Термін дії — автоматичний розрахунок на основі налаштувань типу
  • Текст довідки — автоматична генерація з шаблону

Друк (PDF)

  • Стандартний звіт — для всіх типів довідок
  • Власні звіти — можливість налаштувати для кожного типу
  • Формат A4 — стандартний формат друку

Реєстр довідок

  • Список всіх виданих довідок
  • Фільтри за типом, працівником, статусом, датою
  • Статистика по типах довідок
  • Історія змін (трекінг через mail.activity)

Інтеграція з картою працівника

  • Кнопка "Створити довідку" на формі працівника
  • Список виданих довідок на вкладці працівника
  • Лічильник довідок

Залежності
