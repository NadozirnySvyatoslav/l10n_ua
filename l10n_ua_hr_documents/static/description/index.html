Можливості системи наказів

  • Автоматична нумерація — окремі послідовності для кожного типу наказу
  • Автозаповнення теми — на основі типу наказу
  • Прив'язка до працівника — з автозаповненням підрозділу та посади
  • HTML-редактор контенту — повноцінне форматування тексту наказу
  • Статуси наказу — чернетка / підтверджено / скасовано
  • Історія змін — трекінг всіх змін через mail.activity

Особова справа

Повноцінне ведення особових справ працівників:

Основні дані

  • Номер особової справи
  • Прив'язка до працівника
  • Місце народження
  • Освіта (рік закінчення, кваліфікація)
  • Військовий облік
  • Сімейний стан

Члени сім'ї

  • Відношення (чоловік/дружина, дитина, батьки)
  • ПІБ
  • Дата та місце народження

Документи

  • Типи: паспорт, ID-картка, диплом, медичні
  • Номер та дата видачі
  • Ким виданий
  • Термін дії
  • Вкладення файлів

Трудова історія

  • Записи: прийняття, переведення, звільнення
  • Організація та посада
  • Період роботи
  • Номер та дата наказу

Друк наказів (PDF)

  • Стандартний формат A4
  • Шапка з реквізитами компанії
  • Місце для підпису керівника
  • Поле "Ознайомлено"
