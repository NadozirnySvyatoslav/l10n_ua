Вибір форми друку рахунку

Кнопка «Друк» на проведеному рахунку чи рахунку постачальника відкриває вікно з переліком друкованих форм — тих самих, що в меню ⚙ → Друк: Рахунок-фактура, Акт виконаних робіт, Видаткова накладна, Invoice PDF тощо. Більше не треба шукати потрібну форму під шестернею.

  • Форма за замовчуванням (шаблон контрагента чи журналу, інакше Invoice PDF) вибрана наперед.
  • Показуються лише форми, які користувач бачить у меню «Друк» (групи, права доступу, домен звіту).
  • Якщо доступна одна форма — вона друкується одразу, без вікна.

Invoice print dialog

The Print button of a posted invoice or bill asks which report to print, offering the same reports as the gear menu → Print. The default report is preselected; with a single report it prints right away.
