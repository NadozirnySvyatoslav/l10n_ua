monobank: платежі на підпис у застосунку

Платіжні доручення готуються в monobank через Corporate API (/ext/v1/payment/prepare) і підписуються директором у застосунку або web-кабінеті monobank — без КЕП в Odoo.

  • Звичайні й бюджетні платежі (код виду сплати, додаткова інформація, фактичний платник).
  • Ідемпотентне надсилання: повтор після збою мережі не створює дубль.
  • Стан платежу з банку: очікує підпису, відхилено, у виписці; автоматичне зв'язування з рядком виписки.

Потрібен токен Corporate API з web-кабінету monobank (web.monobank.ua) і підключення l10n_ua_bank_mono в режимі «Corporate API».
