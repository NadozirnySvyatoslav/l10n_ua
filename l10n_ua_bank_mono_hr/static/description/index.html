monobank: зарплата через Corporate API

Зарплата юридичної особи через monobank Corporate API.

  • Зарплатна відомість замість файлу: пакети по 1000 одержувачів, фіналізація, статус і причина відхилення.
  • Синхронізація зарплатних контактів: РНОКПП або паспорт, IBAN, розбіжності.
  • Розрахункові листи в застосунку monobank: завантаження, публікація працівникам, PDF.

Потрібен токен Corporate API з web-кабінету monobank (web.monobank.ua) і підключення l10n_ua_bank_mono в режимі «Corporate API».
