# Заклади освіти

← [Назад до головної](../README.md)

Облік для українських освітніх установ: контингент, навчальні групи, стипендії, харчування, інтеграція з ЄДЕБО.

Легенда статусів: ✅ Стабільний · 🟢 Робочий · 🟡 Бета · 📦 Збірка

| Модуль | Версія | Статус | Призначення |
|--------|--------|--------|-------------|
| `l10n_ua_education` | 19.0.1.0.0 | 📦 | Збірка повного стеку для освіти |
| `l10n_ua_education_base` | 19.0.1.0.0 | 🟡 | База: типи установ, контингент, групи |
| `l10n_ua_education_scholarship` | 19.0.1.0.0 | 🟡 | Стипендії учнів і студентів |
| `l10n_ua_education_meals` | 19.0.1.0.0 | 🟡 | Облік дитячого харчування (ЗДО/ШНЗ) |
| `l10n_ua_education_edebo` | 19.0.1.0.0 | 🟡 | Інтеграція з ЄДЕБО |
| `l10n_ua_education_edebo_xml` | 19.0.1.0.0 | 🟡 | XML-формат обміну з ЄДЕБО (МОН) |

---

## Огляд

- **base** — типи освітніх установ, облік контингенту (учні/студенти), навчальні групи.
- **scholarship** — типи стипендій, відомості виплати, життєвий цикл нарахування (залежить від `l10n_ua_budget_base`).
- **meals** — облік дитячого харчування для закладів дошкільної (ЗДО) та шкільної освіти.
- **edebo / edebo_xml** — імпорт/експорт контингенту з Єдиної державної електронної бази освіти (ЄДЕБО).

> Напрям у стадії бета-розробки.
