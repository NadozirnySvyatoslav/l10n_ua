під час тестування — дані не видаляються.

## Скріншоти

Реальні скріншоти зі звірених доменів — у теках `img/<домен>/` (захоплено з демо-сервера).
Решта позначені іменованими плейсхолдерами (`> _Скриншот:_ name.png`) — їх можна догенерувати.

**Як згенерувати/оновити скріншоти:** скрипт [`capture_screenshots.py`](capture_screenshots.py)
через Playwright (headless Chromium) логіниться в демо й зберігає PNG у `img/<домен>/`:

```bash
python3 capture_screenshots.py           # логін demo/demo (публічний демо-доступ)
# або перевизначити: PW_BASE=... PW_LOGIN=... PW_PASSWORD=... python3 capture_screenshots.py
```

Потрібен `pip install playwright && playwright install chromium`.

## Наскрізь звірені значення (приклади з демо)

- **HR — розрахунковий лист РЛ-2026-00048:** нарахування 50 000 ₴ → ПДФО 18 % = 9 000 ₴,
  ВЗ 5 % = 2 500 ₴, ЄСВ 22 % = 11 000 ₴ (роботодавець) → до виплати **38 500 ₴**.
- **Бухгалтерія — ОЗ-0005 «Планшет»:** метод «зменшення залишку», місячна амортизація
  582,12 ₴; 4 проведені рядки → знос 2 536,27 ₴; проведення формує Дт витрати / Кт 131.
- **Податки — декларація з ПДВ 02/2026:** кредит 31 920,60 − зобов'язання 12 043,60 =
  **до відшкодування 19 877,00 ₴**.
- **Договори:** 5 договорів (Послуги / Абонентське / Підряд), стани Чернетка → Підписаний,
  додаткова угода №1.
- **Освіта:** контингент 125 учнів (life-cycle Заявник→…→Випущено); 2 стипендіальні
  відомості (10 000 ₴ і 9 000 ₴, «Затверджено»).
