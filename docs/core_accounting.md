## l10n_ua_account_base — Фундамент локалізації

**Призначення:** Базовий модуль для всіх українських локалізацій — довідники, валідації, міксини та базовий облік за П(С)БО. Залежність майже для всіх інших модулів. Залежить від `account` та `l10n_ua`.

| Модель | Опис |
|--------|------|
| `l10n_ua.koatuu` | Довідник КАТОТТГ/КОАТУУ (19000+ записів) |
| `l10n_ua.kved` | Класифікатор КВЕД-2010 (1500+ записів) |
| `l10n_ua.tax.office` | Податкові інспекції (ДПІ) |
| `l10n_ua.legal.form` | Організаційно-правові форми (19) |
| `l10n_ua.journal.order` | Журнали-ордери №1-7 |
| `l10n_ua.osv` | Оборотно-сальдова відомість (ОСВ) |
| `l10n_ua.subconto.type` / `l10n_ua.subconto` | Аналітичні виміри (субконто) |

**Розширення `res.partner`:** ЄДРПОУ (8 цифр з контрольною сумою), ІПН/РНОКПП (10 цифр), КВЕД.

**Розширення `account.account`:** клас рахунку (`ua_class`), субрахунок, тип аналітики — план рахунків за П(С)БО (класи 0-9).

**Розширення `account.move`:** український тип та номер документа (`ua_doc_type`, `ua_doc_number`).

**Міксини:** `l10n_ua.address.mixin` (український формат адрес), `l10n_ua.document.mixin` (форматування дат і сум).

**Тести (`tests/`):** `test_validators.py` (ЄДРПОУ/ІПН/IBAN), `test_formatters.py` (суми/дати прописом), `test_osv.py` (ОСВ).

## l10n_ua_accounting — Функціонал бухгалтера

**Призначення:** Повноцінний бухгалтерський пакет (application). Кореневе меню «Бухгалтерія UA». Значний набір залежностей: `l10n_ua_account_base`, `l10n_ua_doc_reports`, `l10n_ua_tax`, `l10n_ua_tax_cabinet`, `l10n_ua_bank_sync`, `l10n_ua_assets`, `l10n_ua_bank_currency_sync`, `l10n_ua_account_vat`.

**Ключові моделі та можливості:**

| Область | Реалізація |
|---------|------------|
| Касові ордери | ПКО (КО-1) та ВКО (КО-2) на `account.payment`, автонумерація за касовим журналом |
| Касова книга | Візард `cash_book_wizard`, добові рухи, залишки, друк |
| Ліміт каси | Крон `cash_limit_cron` контролю залишку |
| Акти звірки | Візард `reconciliation_act_wizard`, сальдо по контрагенту |
| Акти наданих послуг | Модель `service_act` + звіт |
| Авансовий звіт | Модель `advance_report` (підзвітні особи) |
| Баланс (Ф.№1) | `l10n_ua.balance.report` з порівнянням періодів, PDF |
| Звіт про фінрезультати (Ф.№2) | `l10n_ua.pnl.report`, PDF |
| Рух грошових коштів (Ф.№3) | `l10n_ua.cashflow.report` — прямий метод, класифікація за кореспондуючим рахунком, PDF/XLSX |
| Закриття періоду | `l10n_ua.period.closing`, `l10n_ua.tax.period` |
| Звіт старіння заборгованості | `l10n_ua.aging.report` |
| Платіжне доручення | Візард `payment_order_wizard` + звіт |
| Акт інвентаризації | Візард `inventory_act_wizard` |

**Розширення:** `res.company` (реквізити), `account.journal`, `account.payment` (узгодження платежів).

**Тести (`tests/`):** широке покриття — касові ордери, ліміт каси, аналітика каси, узгодження платежів, баланс/фінрезультати, старіння, закриття періоду, акти послуг, non-UA компанія.

> План рахунків, ОСВ та журнали-ордери реалізовані в `l10n_ua_account_base`.

## l10n_ua_account_subconto_hr — Субконто: підрозділи HR

**Призначення:** Міст між `l10n_ua_account_base` та `hr`. Дозволяє використовувати підрозділ (Підрозділ, `hr.department`) як аналітичний вимір (субконто) на рядках проводок. `auto_install = True` — встановлюється автоматично, коли присутні обидві залежності.

- Запис `l10n_ua.subconto.type` для `hr.department`
- Поле швидкого доступу `subconto_department_id` на `account.move.line`
- Базовий модуль обліку залишається без залежності від HR — міст вмикається лише за потреби.

**Тести:** `test_department_subconto.py`.

## l10n_ua_assets — Основні засоби

**Призначення:** Українська локалізація обліку основних засобів. Залежить від `account`, `hr`, `l10n_ua_account_base`, `l10n_ua_doc_reports`.

| Модель | Опис |
|--------|------|
| `l10n_ua.asset` | Картка ОЗ, введення в експлуатацію, амортизація, списання |
| `l10n_ua.asset.depreciation` | Рядки нарахованої амортизації + проводки |
| `l10n_ua.asset.group` | Групи ОЗ 1-16 за ПКУ, рахунки за замовчуванням |
| `l10n_ua.asset.revaluation` | Переоцінка ОЗ за П(С)БО 7 з проводками |
| `l10n_ua.asset.modernization` | Модернізація/реконструкція за П(С)БО 7 п.14 |
| `l10n_ua.asset.inventory` | Інвентаризація (Наказ Мінфіну №879), Інв-1/Інв-3 |
| `l10n_ua.mnma` | МНМА зі списанням 50/50 або 100% |

**Методи амортизації:** прямолінійний, зменшення залишку, виробничий, кумулятивний; з урахуванням ліквідаційної вартості.

**Проводки амортизації (нове):** метод `l10n_ua.asset.depreciation.action_post` формує та проводить бухгалтерський запис у головну книгу — **Дт рахунок витрат** (23/91/92/93/94) / **Кт 131 «Знос ОЗ»** на суму місячної амортизації. Рахунки беруться з поля активу, а за відсутності — з групи ОЗ (`expense_account_id`, `depreciation_account_id`, `depreciation_journal_id`). `action_draft` розпроводить і видаляє відповідний `account.move`. Коригувальні рядки переоцінки власних проводок не створюють (їх формує документ переоцінки).

**Друковані форми:** інвентарна картка ОЗ-6, акт введення в експлуатацію, акт списання, Інв-1/Інв-3, акти переоцінки та модернізації, акти введення/списання МНМА.

**Тести (`tests/`):** `test_asset.py`, `test_depreciation_posting.py`, `test_inventory.py`, `test_mnma.py`, `test_modernization.py`, `test_revaluation.py`.

## l10n_ua_doc_reports — Друковані первинні документи

**Призначення:** QWeb-шаблони PDF для українських комерційних документів. Залежить від `l10n_ua_account_base` та `sale`. Використовується модулями бухгалтерії, ОЗ, ФОП тощо.

- **Рахунок-фактура** — на `sale.order` та `account.move`
- **Видаткова накладна** — на `account.move`
- **Акт виконаних робіт / наданих послуг** — на `account.move`

Усі шаблони містять реквізити компанії й контрагента (ЄДРПОУ, ІПН, банк), суму прописом, підсумки знижок, блоки підписів, спільні українські стилі та формат А4. Розширення моделей — `account_move.py`, `sale_order.py` (допоміжні поля/методи для звітів). Окремих тестів немає.

## l10n_ua_full — Повна локалізація

**Призначення:** Мета-пакет (📦) без власних моделей — лише `depends`, що встановлює повний набір модулів української локалізації Odoo 19: HR та зарплата, бухгалтерія й податки, банки, доставка, маркетплейси, ПРРО (Checkbox). Версія 19.0.1.0.0, `application = True`.
