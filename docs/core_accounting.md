## l10n_ua_account_base — Фундамент локалізації

**Призначення:** Базовий модуль для всіх українських локалізацій — довідники, валідації, утиліти та базовий облік. Залежність майже для всіх інших модулів.

| Модель | Опис | Записів |
|--------|------|---------|
| `l10n_ua.kved` | Класифікатор КВЕД-2010 | ~1000 |
| `l10n_ua.koatuu` | Довідник КАТОТТГ | 19000+ |
| `l10n_ua.tax.office` | Податкові інспекції (ДПІ) | ~40 |
| `l10n_ua.legal.form` | Організаційно-правові форми | 19 |
| `l10n_ua.journal.order` | Журнали-ордери (№1-7) | — |
| `l10n_ua.osv` | Оборотно-сальдова відомість | — |

**Розширення `res.partner`:** ЄДРПОУ (8 цифр з контрольною сумою), ІПН/РНОКПП (10 цифр), КВЕД.

**Розширення `account.account`:** План рахунків України (класи 0-9), українська класифікація.

**Утиліти (`tools/`):**
- `validators.py` — валідація ЄДРПОУ, ІПН, IBAN
- `formatters.py` — форматування дат, сум українською

## l10n_ua_accounting — Функціонал бухгалтера

> **Оновлено:** раніше модуль був заглушкою (PLANNED). Зараз — повноцінний пакет (v7, ~4800 рядків коду, 8 тестів).

- Кореневе меню «Бухгалтерія UA»
- ПКО (Прибутковий касовий ордер, КО-1)
- ВКО (Видатковий касовий ордер, КО-2)
- Касова книга
- Акти наданих послуг
- Акти звірки взаєморозрахунків
- Баланс (Форма №1), Звіт про фінрезультати (Форма №2)

> План рахунків, ОСВ та журнали-ордери реалізовані в `l10n_ua_account_base`.

## l10n_ua_assets — Основні засоби

- Групи ОЗ за ПКУ (1-16)
- Методи амортизації: прямолінійний, зменшення залишку, виробничий, кумулятивний
- Інвентарна картка ОЗ-6, акти, інвентаризація
- Переоцінка та модернізація
- МНМА: списання 50/50 або 100%

## l10n_ua_doc_reports — Первинні документи

Друковані форми комерційних документів (використовується модулями ФОП, ОЗ тощо):

- Акт виконаних робіт/наданих послуг
