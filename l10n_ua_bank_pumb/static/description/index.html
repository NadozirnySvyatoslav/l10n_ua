Банківські виписки через Open Banking API ПУМБ для Odoo 19

Про модуль

Модуль отримує виписки рахунків ПУМБ через Open Banking API (стандарт Berlin Group NextGenPSD2) і формує з них банківські виписки Odoo.

Розширює базовий модуль l10n_ua_bank_sync функціоналом, специфічним для ПУМБ.

Основні можливості

  • Захищене з'єднання mTLS із сертифікатом відкритого банкінгу (QWAC): PEM, DER або PKCS#12
  • Згода клієнта на доступ до рахунку: створення, підтвердження в застосунку ПУМБ Online, оновлення статусу, відкликання
  • Імпорт проведених операцій за період (до 31 дня) з посторінковим завантаженням
  • Визначення напрямку операції, контрагента та його IBAN
  • Автоматична синхронізація за розкладом і повторна обробка збереженої відповіді банку
  • Тестове (sandbox) і робоче середовища

Як підключити

  1. Створіть підключення банку з провайдером ПУМБ (Open Banking) і банківським журналом рахунку.
  2. Завантажте сертифікат і приватний ключ, заповніть PSU ID (IBAN рахунку або логін ПУМБ Online); для юросіб — IBAN юрособи.
  3. Натисніть «Створити згоду» і підтвердіть її в застосунку ПУМБ Online.
  4. Натисніть «Оновити згоду» — після підтвердження модуль отримає ідентифікатор рахунку, і можна синхронізувати виписки.

Вимоги та обмеження

  • Встановлений модуль l10n_ua_bank_sync
  • Сертифікат відкритого банкінгу типу QWAC (для sandbox — тестові ключі ПУМБ)
  • Згода діє до 90 днів; без участі клієнта — до 4 звернень до рахунку на добу
