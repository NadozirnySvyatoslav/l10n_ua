Документи

  • РНОКПП (ІПН) з автоматичною валідацією контрольної суми
  • Паспорт старого зразка або ID-картка
  • Серія, номер, ким і коли виданий
  • Унікальний запис в реєстрі (для ID-карток)

Адреси

  • Адреса реєстрації (область, місто, індекс)
  • Фактична адреса проживання
  • Позначка "співпадає з реєстрацією"

Освіта

  • Рівень освіти (від дошкільної до доктора наук)
  • Навчальний заклад та спеціальність
  • Дані диплому (серія, номер, дата)

Військовий облік

  • Статус: військовозобов'язаний / заброньований / звільнений
  • Категорія обліку (1, 2, знятий)
  • Військове звання та ВОС
  • Придатність до служби
  • ТЦК (територіальний центр комплектування)
  • Бронювання та термін дії

Пільги

  • Група інвалідності (I, II, III)
  • Категорія чорнобильця (1-4)
  • Статус ветерана
  • Інші пільги для ПСП

Сім'я

  • Сімейний стан
  • Дані про чоловіка/дружину (ПІБ, РНОКПП)
  • Облік дітей з датами народження та статусом утриманця
  • Автоматичний підрахунок утриманців для ПСП

Стаж та банк

  • Дата прийняття на роботу
  • Загальний трудовий стаж
  • Автоматичний розрахунок стажу в компанії
  • Страховий стаж для лікарняних
  • Банківський рахунок для зарплати

Штатний розпис

Штатний розпис підприємства

Повноцінний облік штатного розпису підприємства:

  • Структура — підрозділи та посади
  • Штатні одиниці — кількість ставок (0.5, 1.0, 2.0...)
  • Автоматичний підрахунок — зайнятих та вакантних позицій
  • Оклади — посадові оклади з мін/макс межами та фонд оплати праці
  • Історія — дати введення в дію, номер наказу
  • Статуси — чернетка / затверджено / архів

Збір на українську локалізацію Odoo — заміна 1С для бізнесу

Привіт! Створюю відкриті модулі української локалізації Odoo для повноцінної заміни 1С:

  • 📊 Бухгалтерський та фінансовий облік за українськими стандартами
