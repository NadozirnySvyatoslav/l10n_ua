Ukraine - LiqPay Payment Provider

Card payments on your website and customer portal through LiqPay (PrivatBank) for Odoo 19

About

A standard Odoo payment provider (payment.provider) for the LiqPay internet acquiring of PrivatBank. It works wherever Odoo takes online payments: the eCommerce checkout, the customer portal (invoices, quotations) and payment links.

The customer is redirected to the LiqPay Checkout page (https://www.liqpay.ua/api/3/checkout), pays there and comes back to the Odoo payment status page. The module follows the official LiqPay API documentation (API version 7).

Features

  • Checkout form built from signed data + signature (SHA3-256), with the order reference as order_id
  • The payment state is set only from a LiqPay callback whose signature matches your private key (constant-time comparison), or from the LiqPay payment status API queried with your own keys
  • The amount and currency of every callback are checked against the transaction: a mismatch never confirms an order
  • Full mapping of LiqPay statuses: paid, waiting for confirmation (3DS, OTP, Privat24...), declined, reversed
  • Full and partial refunds from Odoo through the LiqPay API; refunds made in the LiqPay cabinet are recorded from the callback
  • Currencies: UAH, USD, EUR
  • Test mode with LiqPay sandbox keys; sandbox keys are refused in live mode and sandbox payments never confirm a live order
  • The private key is visible to administrators only and is cleared when a database is neutralized

Configuration

  1. In the LiqPay cabinet (Settings → API of your shop) copy the public_key and private_key. Test keys start with sandbox_.
  2. In Odoo open Website / Invoicing → Configuration → Payment Providers → LiqPay, paste the keys and set the state to Test Mode (sandbox keys) or Enabled (live keys).
  3. Make sure the web.base.url of the database is the public HTTPS address of the website: LiqPay sends the callback to /payment/liqpay/webhook and returns the customer to /payment/liqpay/return on that address. Both are sent with each payment, nothing has to be entered in the cabinet.
  4. Test card for sandbox payments: 4242 4242 4242 4242, any future expiry date, any CVV.

Requirements

  • A LiqPay merchant (shop) account
  • The Odoo server must be reachable from the Internet over HTTPS for the callbacks
  • Other currencies than UAH, USD and EUR must be enabled by LiqPay on request and are not offered by the module
