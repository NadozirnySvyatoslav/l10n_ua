Параметри PSP

Централізоване управління податковими параметрами:

  • Прожитковий мінімум — для розрахунку ПСП
  • Мінімальна зарплата — для ЄСВ та валідації
  • Ставки податків — ПДФО, ВЗ, ЄСВ
  • Граничний дохід — автоматичний розрахунок
  • Максимальна база ЄСВ — 15 мін. зарплат

Формула розрахунку

1. Нарахування:
  Gross = Оклад + Надбавки + Премії + Відпускні + Лікарняні

2. ПСП (якщо дохід ≤ ліміту):
  PSP = 50% × Прожитковий мінімум (або 75%, 100%)

3. ПДФО:
  PDFO = (Gross - PSP) × 18%

4. Військовий збір:
  Military = Gross × 5%

5. ЄСВ (роботодавець):
  ESV_base = min(max(Gross, MinWage), 15×MinWage)
  ESV = ESV_base × 22%

6. До виплати:
  Net = Gross - PDFO - Military - Інші_утримання
